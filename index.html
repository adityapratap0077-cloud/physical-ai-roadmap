A beginner walkthrough

Zero to Robots

Six steps. Each one tells you exactly what to click, install, and type. No AI knowledge needed. No experience needed. By the end, you will have trained AI and driven robots yourself.

Before you start, you need

  • A computer. Any laptop works. Windows, Mac, or Linux.
  • Internet. Most steps run in your browser, nothing to install.
  • A Google account. For the free tools in steps 2, 3, and 5.
  • Zero experience. Every new word is explained the first time you meet it.
  • Zero money. Every step in this walkthrough is free.
Step 1Takes about 1 hour · Free

Write code by talking to AI

You will make the computer do things by describing them in plain English. The AI writes the code. You just run it and watch.

First, the words

PromptWhat you type to the AI. Like giving instructions to a very fast assistant.
Code editorThe app where code lives. Think of it as a notebook that can run what you write.
RunMaking the code actually do its thing, instead of just sitting there as text.

Your moves

  1. Go to cursor.com and download Cursor. Install it like any normal app, then open it.
  2. Click New File, then save it as hello.py. The .py ending means this file speaks Python, the language we will use everywhere.
  3. Press Ctrl+K (or Cmd+K on Mac). A small box appears. Type: print my name 5 times, but write your real name. Press Enter and let the AI write the code.
  4. Now run it. Open the terminal inside Cursor (Terminal menu, then New Terminal) and type python hello.py, then press Enter. You should see your name printed 5 times.If it says python is not found, install Python from python.org first, then try again.
  5. Do it once more, but harder. Press Ctrl+K again and type: ask for my name, then greet me by name. Run it. Talk to your own program.

You are done when

  • You made the computer print your name 5 times
  • You made a program that asks for a name and greets the person
  • You changed a prompt and saw the code change with it
Step 2Takes about 2 hours · Free · Runs in your browser

Teach your computer to see

You will point an AI at a photo and watch it name everything in it. This is exactly how robots see the world.

First, the words

ModelA file that already learned to recognize things. You download it, you do not build it.
DetectionDrawing boxes around objects in a photo and naming each one.
PixelOne tiny dot of color. A photo is just a grid of millions of them.

Your moves

  1. Go to colab.research.google.com, sign in with Google, and click New notebook. This is a free computer in your browser. Nothing to install.
  2. In the first box, type !pip install ultralytics and press Shift+Enter to run it. Wait until it finishes. Installing takes a few minutes the first time, that is normal.
  3. Click + Code to add a new box, paste this in, and run it with Shift+Enter: 
    # Load an AI model that already knows what everyday objects look like
from ultralytics import YOLO
model = YOLO("yolo11n.pt")

# Point it at a photo and save the result
results = model("https://ultralytics.com/images/bus.jpg")
results[0].save()
  4. Click the folder icon on the left side. Open runs, then detect, then the newest predict folder. Double-click the image. You will see boxes drawn around the people and the bus, with names on each box. The AI saw the photo.
  5. Now try your own photo. Click the upload button at the top of that same folder panel and upload any photo from your phone. Then change the web address in your code to your file name, like model("my-photo.jpg"), and run it again. Check what the AI finds in your photo.

You are done when

  • You saw boxes and labels on the sample bus photo
  • You uploaded your own photo and the AI labeled things in it
  • You can explain what a model is, in your own words
Step 3Takes about 1 hour · Free · No code at all

Train your own AI

Ready-made models recognize common things. Now you will teach a model something only you can teach it: your own hand gestures. Zero code needed.

First, the words

TrainingShowing the AI many examples until it learns the pattern by itself.
ClassOne category you invent, like "thumbs up". You will make two.
DatasetYour pile of examples. More varied examples means a smarter model.

Your moves

  1. Go to teachablemachine.withgoogle.com, click Get Started, then choose Image Project.
  2. Rename Class 1 to thumbs up and Class 2 to thumbs down.
  3. Under "thumbs up", click Webcam, allow camera access, then hold the record button. Show lots of thumbs up: move your hand around, tilt it, change the distance. Aim for a few hundred pictures. It goes fast. Then do the same for "thumbs down".Variety matters more than quantity. Different angles and lighting teach it better.
  4. Click Train Model. Wait about 30 seconds while it learns.
  5. Test it on the right side of the screen. Give a thumbs up, then a thumbs down, and watch the bars move. It is reading your hand live.

You are done when

  • The preview tells your thumbs up from thumbs down correctly, most of the time
  • You tried to fool it (different angle, other hand) and saw where it fails
  • You can explain what training means, in your own words
Level up: click Export Model on the site. It gives you code to use your model in a real webpage.
Step 4Takes a weekend · Free · The hardest setup in this walkthrough

Learn robot software

Real robots run on software called ROS 2. You will install it and drive a virtual robot with your keyboard. No real robot needed.

First, the words

ROS 2The free software most real robots run. Think of it as the robot's operating system.
NodeOne small program. A robot is a team of nodes working together: one sees, one moves, one decides.
TopicThe channel nodes use to talk to each other. Like a group chat for programs.
SimulationA fake 3D world where you practice with robots safely and for free.

Your moves

  1. ROS 2 needs Ubuntu Linux. If you use Windows or Mac, install Ubuntu inside a free virtual machine (VirtualBox) or as a dual boot. This one-time setup is the longest part of the step. Give it an afternoon.This is the only step with real setup pain. Every step after this is smooth again.
  2. Follow the official ROS 2 Jazzy install guide. Go slowly, one command at a time.
  3. Test that it works. Open two terminals. In the first one, run: 
    source /opt/ros/jazzy/setup.bash
ros2 run demo_nodes_cpp talker
    In the second one, run: 
    source /opt/ros/jazzy/setup.bash
ros2 run demo_nodes_py listener
    You should see the listener printing everything the talker says. Two programs, talking through ROS 2. That means your robot software works.
  4. Now the fun part. Install the simulator with sudo apt install ros-jazzy-ros-gz, open it with gz sim, and work through the official beginner tutorials to drive a simulated robot with your keyboard.

You are done when

  • The talker and listener talked to each other in your two terminals
  • You opened the simulator and moved a virtual robot with your keyboard
  • You can explain what a node and a topic are, in your own words
Step 5Takes about 2 hours · Free · Runs in your browser

Give AI a brain that plans

A chatbot answers one question. An agent breaks a goal into steps and works through them. You will connect an AI brain to your own code and watch it plan.

First, the words

AgentAI that plans and acts toward a goal, not just chats.
API keyA password that lets your code use Google's AI. Free to get, keep it private.
ToolSomething an agent can use to get things done, like a calculator or web search.

Your moves

  1. Go to aistudio.google.com, sign in, click Get API key, then Create API key. Copy it somewhere safe. It is free, and it works like a password, so never post it anywhere public.
  2. Open a new notebook at colab.research.google.com. Back in AI Studio, click Get code. It gives you a short Python snippet with your key already filled in. Paste it into your notebook and run it with Shift+Enter. You just called an AI brain from your own code.
  3. Now make it plan. Add a new box and ask it for something with steps, for example: Plan a 2-day trip to Jaipur under 5000 rupees. Break it into clear steps. Read the plan it returns.
  4. Now make it check itself. Ask: Review your plan above. Find mistakes or missing costs, and give me a fixed version. Watch it criticize and improve its own work. That plan-then-check loop is the heart of every AI agent.

You are done when

  • Your code called the AI using your own API key
  • It produced a step-by-step plan for your goal
  • It checked its own plan and improved it
Level up: libraries like LangGraph let agents use real tools (search, calculators, code). That is your next rabbit hole.
Step 6Takes a weekend · Free in simulation

Put AI on a robot

Time to combine everything: an AI brain driving a robot body. You will train a robot arm in simulation first. Real hardware comes later, and it is optional.

First, the words

PolicyThe trained AI that decides the robot's next move, moment by moment.
Imitation learningThe robot learns by watching demonstrations, the way you learned by watching others.
Sim-to-realTraining in simulation first, then running the same AI on a real robot later.

Your moves

  1. Install LeRobot, the open-source toolkit for teaching robots. You need Python 3.10 or newer. Then run pip install lerobot. The full guide is at huggingface.co/docs/lerobot/installation.
  2. Add a simulation world to practice in: pip install "lerobot[pusht]". PushT is a classic beginner task: a simulated arm pushes a T-shaped block to a target.
  3. Follow LeRobot's docs to train a small policy on the PushT task. Training runs on a normal CPU, slowly, or on a free Colab GPU, faster. When it finishes, watch your trained arm push the block to the target by itself.
  4. Real hardware is optional and comes later. When you are ready, a popular DIY robot arm kit costs around $200. You record about 50 demonstrations by moving the arm yourself, train on them, and the arm repeats the task on its own.

You are done when

  • LeRobot is installed and the PushT simulation opens
  • Your trained policy moved the block to the target on its own
  • You can explain imitation learning in one sentence

You did it. Now go build.

You can write code by talking to AI. You can make computers see. You can train your own models. You can run robot software. You can call AI brains from code. You can train robot policies. That is the full path from zero to physical AI.

Pick one small project and build it end to end. A good first one: a robot arm in simulation that sorts objects by color. It uses every step you just finished.
